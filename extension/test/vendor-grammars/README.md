Copies of the built-in grammars our grammar embeds, so the grammar tests run without
a VS Code install. Taken unmodified from VS Code 1.143.1
(`resources/app/extensions/{html,vb,javascript,css}/syntaxes/`), MIT-licensed by Microsoft; see each
file's `information_for_contributors` for upstream sources.

Not shipped in the extension: at runtime VS Code supplies its own copies.
