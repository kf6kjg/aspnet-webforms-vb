# server

Language server (separate .NET process) hosting a synthetic, in-memory Roslyn VB
workspace for a Web Site project. **Not started.**

The [feasibility spike](../spike) shows the core approach works on Linux; see
[docs/spike-results.md](../docs/spike-results.md) and
[ADR 0002](../docs/adr/0002-roslyn-workspace-with-nuget-reference-assemblies.md).
